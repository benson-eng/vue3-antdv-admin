# 分類
## api mock
- 使用 MSW 進行 api mock 服務
- /mocks/

## api generate
- 使用 openapi 生成 api 文件
- 配置檔 openapi.config.ts
  
- /src/api/backend 自動生成
    ```bash
    pnpm openapi:generate
    ```
## 資料儲存 
- 使用 pinia 進行資料存取與管理
- /src/store/

## 權限管理
- 定義 PermissionType
    ```ts
    export type PermissionType = 
        'system:role:list',
        'system:role:create',
        'system:role:read',
        'system:role:update',
        'system:role:delete',
        'system:menu:list',
        'system:menu:create',
        'system:menu:read',
        'system:menu:update',
        'system:menu:delete',
    ```
- 定義路由權限
- src/router/asyncModules 中配置
- 透過 api 取得使用者權限
- api: /account/permissions
- 詳見 [權限管理系統](./權限管理系統.md)

## 共用邏輯
- 使用 hooks 
- /src/hooks/
- 命名規範: useXXX.ts
- 使用範例:
    ```ts
    import { useXXX } from '@/hooks/useXXX';
    const xxx = useXXX();
    ```

## 多國語系
- 使用 vue-i18n 進行多國語系管理
- /src/locales/
- 特定語系 /src/locales/{lang}
