# 環境變數轉換指南（Vue 2 → Vue 3）

## 轉換規則

### Vue 2 → Vue 3 環境變數前綴
- **Vue 2**: `VUE_APP_*` → **Vue 3**: `VITE_*`
- **Vue 2**: `process.env.VUE_APP_*` → **Vue 3**: `import.meta.env.VITE_*`

### 常見轉換範例

| Vue 2 | Vue 3 |
|-------|-------|
| `VUE_APP_BASE_API` | `VITE_BASE_API_URL` |
| `VUE_APP_TITLE` | `VITE_APP_TITLE` |
| `VUE_APP_CDN_BASE_URL` | `VITE_APP_CDN_BASE_URL` |

## 使用方式

請提供您的 Vue 2 專案的 `.env.development` 內容，AI 會自動轉換為 Vue 3 格式。

## 本專案使用的環境變數

根據專案結構，以下環境變數會被使用：

### 原有專案環境變數
- `VITE_BASE_API_URL` - API 接口路徑（用於 `src/utils/request.ts`）
- `VITE_BASE_URL` - 網站部署的目錄
- `VITE_APP_TITLE` - 網站標題
- `VITE_BASE_SOCKET_PATH` - Socket 請求路徑前綴
- `VITE_BASE_SOCKET_NSP` - Socket 命名空間
- `VITE_MOCK_API` - Mock API 路徑
- `VITE_MOCK_IN_PROD` - 是否在生產環境啟用 mock
- `VITE_DROP_CONSOLE` - 是否移除 console

### 從 Vue 2 專案整合的環境變數
- `VITE_APP_BASE_API` - AdminSystem API 基礎 URL（用於整合的登入 API）
- `VITE_APP_CDN_BASE_URL` - CDN 基礎 URL（可選）

## 注意事項

1. 環境變數檔案應該放在專案根目錄
2. `.env.development` 用於開發環境
3. `.env.production` 用於生產環境
4. `.env.local` 和 `.env.*.local` 會被 git 忽略，可用於本地覆蓋
