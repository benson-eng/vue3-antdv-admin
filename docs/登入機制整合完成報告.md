## 📝 使用說明

### 使用新的登入方法

```typescript
import { useUserStore } from '@/store/modules/user';

const userStore = useUserStore();

// 基本登入（會自動檢測是否需要雙因素驗證）
const result = await userStore.Login({ account: 'username', password: 'password' });

// 如果需要雙因素驗證，result 會返回 true
if (result === true) {
  // 顯示雙因素驗證輸入框
  // 然後調用 Login2
  await userStore.Login2({ 
    account: 'username', 
    password: 'password', 
    backendKey: '123456' 
  });
}

// 取得使用者資訊
await userStore.GetUserInfo();

// 登出
await userStore.LogOut();
```

### API 調用

```typescript
import { loginLocal, getUserInfoLocal, logoutLocal, getBackendKey } from '@/api/users';

// 登入
const response = await loginLocal({ account: 'username', password: 'password' });

// 取得使用者資訊
const userInfo = await getUserInfoLocal({ token: 'your-token' });

// 登出
await logoutLocal({});

// 取得雙因素驗證金鑰
const backendKey = await getBackendKey({ input: { id: 123 } });
```

## ⚠️ 注意事項

1. **Token 格式**: 系統會根據 API 路徑自動選擇 token 格式：
   - `/AdminSystem/` 開頭的 API 使用 `X-Access-Token`
   - 其他 API 使用 `Authorization: Bearer`

2. **雙因素驗證**: 目前 `Login2` 方法中的雙因素驗證邏輯為簡化版本。如果需要完整的驗證邏輯，需要：
   - 安裝 `speakeasy` 和 `base32.js` 套件
   - 實現完整的 TOTP 驗證邏輯

3. **記住帳號**: 使用 localStorage 儲存，key 為 `remember_account`

4. **錯誤處理**: AdminSystem API 的錯誤碼 4、10012、10029 會自動觸發登出並跳轉到登入頁

5. **向後兼容**: 所有原有功能（原有的 `login`、`logout` 等方法）都保留，新方法作為補充
