# Vue 3 + Ant Design Vue 登入機制整合清單

本清單列出需要從 `admin-web` 專案整合到 `vue3-antdv-admin` 專案的所有登入相關檔案。

## 📋 檔案清單

### 1. 登入頁面組件
**來源檔案：** `src/views/login/index.vue`
- 主要登入頁面組件
- 包含帳號、密碼輸入
- 支援雙因素驗證（BackendKey）
- 記住帳號功能
- 需要轉換：Element UI → Ant Design Vue，Vue 2 → Vue 3 Composition API

### 2. 登入 API 調用代碼
**來源檔案：** `src/api/users.ts`
- `loginLocal()` - 登入 API（第 62-67 行）
- `getUserInfoLocal()` - 取得使用者資訊 API（第 68-73 行）
- `logoutLocal()` - 登出 API（第 74-79 行）
- `getBackendKey()` - 取得雙因素驗證金鑰（第 81-92 行）

### 3. 認證相關的 Store/State 管理
**來源檔案：** `src/store/modules/user.ts`
- **主要 Actions：**
  - `Login()` - 登入 Action（第 103-127 行）
  - `Login2()` - 雙因素驗證登入 Action（第 129-165 行）
  - `GetUserInfo()` - 取得使用者資訊 Action（第 176-204 行）
  - `LogOut()` - 登出 Action（第 223-235 行）
  - `ResetToken()` - 重置 Token Action（第 168-173 行）
- **狀態管理：**
  - token、name、avatar、roles、email、account 等
- **需要轉換：** Vuex → Pinia（Vue 3 推薦）

### 4. 請求攔截器配置
**來源檔案：** `src/utils/request.ts`
- 請求攔截器（第 35-65 行）：自動添加 `X-Access-Token` header
- 回應攔截器（第 68-108 行）：處理錯誤、token 過期等情況
- 需要適配：Vue 3 的 store 使用方式

**輔助檔案：** `src/utils/vueRequest.ts`
- Vue 請求封裝函數（處理錯誤訊息）
- 需要適配：Ant Design Vue 的 message 組件

### 5. Token Cookie 管理工具
**來源檔案：** `src/utils/cookies.ts`
- `getToken()` - 取得 token
- `setToken()` - 設定 token
- `removeToken()` - 移除 token
- 可以直接使用，無需修改

### 6. 路由權限控制
**來源檔案：** `src/permission.ts`
- 路由守衛（第 26-78 行）：檢查登入狀態、權限驗證
- 需要轉換：Vue Router 3 → Vue Router 4 API

### 7. 路由配置
**來源檔案：** `src/router/index.ts`
- 登入頁面路由（第 83-87 行）
- 需要適配：Vue Router 4 的路由配置方式

### 8. 依賴的 Store 模組
**來源檔案：**
- `src/store/modules/permission.ts` - 權限管理模組（用於動態路由生成）
- `src/store/modules/status.ts` - 狀態管理模組（用於請求狀態，可選）

### 9. 配置檔案
**來源檔案：** `src/config/apiActionSetting.ts`
- API 動作設定（攔截器中使用）
- 定義哪些 action 需要使用 spinner

### 10. 類型定義
**來源檔案：** `src/api/types.d.ts`
- `IVueResponse` 介面定義（用於 API 回應類型）

## 🔄 主要轉換工作

### Vue 2 → Vue 3
- [ ] Class Component → Composition API
- [ ] `this.$router` → `useRouter()`
- [ ] `this.$t()` → `useI18n()` (如果使用 i18n)
- [ ] Vuex → Pinia
- [ ] Vue Router 3 → Vue Router 4
- [ ] `process.env.VUE_APP_*` → `import.meta.env.VITE_APP_*`

### Element UI → Ant Design Vue
- [ ] `el-form` → `a-form`
- [ ] `el-input` → `a-input`
- [ ] `el-button` → `a-button`
- [ ] `el-checkbox` → `a-checkbox`
- [ ] `el-dialog` → `a-modal`
- [ ] `Message` → `message` (Ant Design Vue)
- [ ] `MessageBox` → `Modal.confirm` (Ant Design Vue)

### 其他注意事項
- [ ] 樣式：可能需要調整 CSS 類名和樣式
- [ ] 圖標：`svg-icon` 組件可能需要替換為 Ant Design Vue 的圖標系統
- [ ] 雙因素驗證：需要安裝 `speakeasy` 和 `base32.js` 套件

## 📝 整合步驟建議

1. **先整合基礎工具**
   - `src/utils/cookies.ts` - Token 管理
   - `src/utils/request.ts` - 請求攔截器（需要適配）

2. **整合 API 層**
   - `src/api/users.ts` - 登入相關 API
   - `src/api/types.d.ts` - 類型定義（IVueResponse）

3. **整合狀態管理**
   - 將 Vuex store 轉換為 Pinia store
   - `src/stores/user.ts` (新檔案，從 `src/store/modules/user.ts` 轉換)

4. **整合路由**
   - 添加登入路由
   - 設置路由守衛（Vue Router 4）

5. **整合登入頁面**
   - 轉換登入組件為 Vue 3 + Ant Design Vue

6. **測試驗證**
   - 測試登入流程
   - 測試 token 過期處理
   - 測試雙因素驗證（如果有）

## 🔗 相關依賴

確保目標專案已安裝：
- `pinia` - 狀態管理
- `ant-design-vue` - UI 組件庫
- `axios` - HTTP 請求
- `js-cookie` - Cookie 管理
- `vue-router@4` - 路由（Vue 3）
- `speakeasy` - 雙因素驗證（如果需要）
- `base32.js` - Base32 編解碼（如果需要）
- `nprogress` - 進度條（路由守衛中使用）

## 📌 重要提示

1. **API 基礎 URL**：需要根據目標專案調整 `src/utils/request.ts` 中的 API 基礎 URL 配置
2. **i18n**：如果目標專案使用不同的 i18n 方案，需要適配翻譯功能
3. **權限系統**：`permission.ts` 中的權限邏輯可能需要根據目標專案的權限系統調整
4. **樣式**：登入頁面的樣式可能需要重新設計以符合 Ant Design Vue 的設計規範
5. **環境變數**：Vue 3 使用 `import.meta.env.VITE_APP_*` 而非 `process.env.VUE_APP_*`
